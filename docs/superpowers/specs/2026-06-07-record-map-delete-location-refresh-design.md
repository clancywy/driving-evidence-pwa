# 处理记录地图、删除和定位刷新设计

## 背景

处理记录卡片已经改成横向滑动，但卡片里的地图窗口仍偏小。用户在 iPhone 17 Pro 上查看时，处理记录下方还有可用空间，应优先把地图显示面积扩大。当前记录没有删除入口；定位使用浏览器 `watchPosition`，但允许最多 5 秒缓存定位，高速行驶时旧定位可能偏离较远。

## 范围

包含：

- 放大处理记录卡片里的地图窗口。
- 为每条处理记录增加删除入口。
- 删除前弹出确认，避免误删。
- 删除后更新本地记录并刷新处理记录页面。
- 将定位参数从 `maximumAge: 5000` 调整为 `maximumAge: 1000`，将 `timeout: 10000` 调整为 `timeout: 5000`。
- 更新 PWA 缓存版本。

不包含：

- 不改变地图坐标来源，仍使用系统原始定位。
- 不新增复杂的撤销、回收站或批量删除。
- 不保证固定每秒刷新一次，因为 iOS 和浏览器最终控制 GPS 推送频率。

## 交互

- 处理记录卡片中的地图高度增大，方便对照行车记录仪。
- 每条记录头部保留时间和状态，并增加红色 `删除` 按钮。
- 点击 `删除` 后显示确认框；确认后删除该记录，取消则不改变记录。
- 定位仍由 `watchPosition` 持续监听，但请求更高的新鲜度，减少高速场景下缓存定位带来的滞后。

## 验收标准

- 处理记录地图窗口明显大于当前 140px。
- 每张处理记录卡片有删除入口。
- 删除确认后，记录从本地保存中移除。
- 取消删除时，记录不变。
- 定位参数为 `maximumAge: 1000` 和 `timeout: 5000`。
- 自动测试和 JS 语法检查通过。
